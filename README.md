# Marketplace. — локальная административная панель

## Что изменено
- Удалён пункт меню и экран «Демо-центр».
- В «Моих подписках» оставлен список подписок без нижнего блока-заглушки будущего этапа.
- Пункт «Админ-панель» показывается только для административных ролей: Владелец, Заместитель владельца, Администратор, Модератор, Стажёр.
- Добавлены разделы админ-панели: обзор, жалобы и оспаривания (базовый workflow), объявления, пользователи и роли, магазины, отзывы, баннеры и уведомления, журнал действий, настройки и FAQ.
- Добавлены пять ролей с разным доступом. Модератор/администратор могут передавать заключение, но окончательное решение доступно владельцу и заместителю. Владелец имеет приоритет над заместителем.
- В админ-панели можно искать жалобы и объявления, сохранять заключение модератора, выносить решение, отклонять жалобу, отправлять дело на дополнительную проверку, изменять роли в локальном интерфейсе и просматривать журнал действий.
- Удаление объявления в доступных действиях выполняется без функции восстановления; в истории просмотров остаётся только запись, что объект больше недоступен.
- Действия и настройки демо-панели сохраняются в localStorage браузера.

## Запуск
```bash
npm install
npm run build
npm run dev
```

## Важные ограничения
Это локальный прототип интерфейса, не production-система управления сообществом. Переключение роли в админ-панели предназначено только для тестирования UI и не является аутентификацией. LocalStorage можно изменить на стороне клиента; данные не синхронизируются между пользователями и устройствами. Для настоящего запуска нужны серверная база данных, Telegram-аутентификация, серверная проверка полномочий, защищённый журнал аудита и централизованная доставка уведомлений. Перед production необходимо выполнить полный build и тесты после установки зависимостей.

## Обновление интерфейса
- Разделы административной панели открываются как боковая выдвижная панель с кнопками «Назад» и «Закрыть»; на телефоне поддерживается свайп справа налево для закрытия.
- В разделе «Баннеры и уведомления» можно создавать, просматривать и удалять баннеры. Баннеры и созданные магазины сохраняются в текущем браузере.
- В FAQ расширен список ответов, кнопка связи оформлена в фирменном градиенте и ведёт в Telegram владельца.
- Убрана отдельная кнопка создания объявления из кабинета магазина; создание объявления доступно через личный кабинет.
- В Telegram Mini App считываются доступные данные `initDataUnsafe.user` (ID, username, имя и фото). Это только отображение данных на клиенте. Для настоящей авторизации, бана по Telegram ID, защищённого назначения ролей и глобального скрытия/восстановления объявлений нужен сервер, который проверяет подпись `initData` и хранит данные в БД. Не используйте `initDataUnsafe` как доказательство личности на сервере.
